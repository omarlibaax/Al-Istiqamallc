# Ali-Istiqama Travel

Run `npm install` and `npm run dev` for local development. Run `npm run build` to generate the static site in `dist/`.

## Contact setup

Set these public Vite variables in `.env.local` and rebuild.

| Variable | Value |
| --- | --- |
| `VITE_CONTACT_EMAIL` | Travel inquiry inbox |
| `VITE_CONTACT_PHONE` | Phone number with country code |
| `VITE_WHATSAPP` | WhatsApp number with country code and digits only |
| `VITE_FACEBOOK_URL` | Agency Facebook profile |
| `VITE_INSTAGRAM_URL` | Agency Instagram profile |
| `VITE_TIKTOK_URL` | Agency TikTok profile |

The travel planner collects and validates inquiry details, then offers copying and configured messaging options. Live availability, payments and booking confirmation require a separate booking integration. Replace the testimonial prompts with approved reviews and portraits, verify the brief’s business figures and package claims, and supply the agency’s booking terms before publishing.
